# 📝 Smart To-Do List Application

> **IBM Professional Certificate Capstone Project**  
A modern, feature-rich, and responsive To-Do List web application built using an AI-assisted development approach (*Vibe Coding*).

---

## 📌 About The Project
Proyek ini adalah tugas akhir (**Capstone Project**) untuk program sertifikasi **IBM**. Aplikasi *Smart To-Do List* ini dikembangkan untuk membantu pengguna mengelola tugas sehari-hari dengan lebih terstruktur, dilengkapi dengan fitur prioritas tugas, penanda waktu, serta antarmuka yang bersih dan intuitif.

Pengembangan proyek ini menggunakan pendekatan **Vibe Coding**—memanfaatkan kecerdasan buatan (*AI assistant*) untuk mempercepat pembuatan struktur kode dan logika pemrograman, yang kemudian disesuaikan serta diuji secara mandiri (*fine-tuning*).

---

## ✨ Features
- ➕ **Add & Delete Tasks:** Tambah dan hapus tugas dengan mudah.
- ✅ **Task Completion:** Tandai tugas selesai dengan efek visual *strikethrough*.
- 🏷️ **Priority Badges:** Kategorisasi tingkat prioritas tugas (**High**, **Medium**, **Low**) dengan penanda warna yang jelas.
- 🗂️ **Filter Tabs:** Saring tampilan tugas berdasarkan status (*All*, *Active*, *Completed*) dan tingkat prioritasnya.
- 💾 **Local Storage Persistence:** Data tugas otomatis tersimpan di browser sehingga tidak hilang saat halaman dimuat ulang.

---
